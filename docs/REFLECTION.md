# Project Reflection

## 1. Use of AI

AI assistance was used throughout the development of the Application Layer Protocol Visualizer.

ChatGPT helped with project planning, Flask development, HTML, CSS, JavaScript, protocol visualization and debugging.

AI assistance made it possible to develop the application structure and interactive protocol visualization more efficiently.

## 2. Synchronization Between the Two Panels

The application uses two main panels.

The left panel contains the user activities:

- Browsing
- Mail
- Streaming

The right panel displays the protocol communication associated with the selected activity.

When an activity is started, its corresponding protocol messages are loaded into the visualization panel.

For example, Browsing displays DNS communication followed by HTTP communication.

## 3. Protocol Differences

The project demonstrates different Application Layer protocols used by different applications.

### Browsing

Browsing uses DNS to resolve the domain name and HTTP to request web resources.

### Mail

Mail uses SMTP to demonstrate communication between a mail client and mail server.

### Streaming

Streaming uses DNS to resolve the server and HTTP to retrieve a manifest and media segments.

These activities show that different applications can use different Application Layer communication sequences.

## 4. AI Errors and Corrections

AI-generated code required testing and integration with the existing project.

The generated components were manually tested to ensure that the Flask backend, HTML interface, CSS styling and JavaScript functionality worked together.

The protocol sequences were also reviewed so that the visualization followed the expected order of Application Layer messages.

The final application uses simulated protocol communication because the assignment permits simulation.

## 5. What I Learned

This project helped me understand Application Layer protocols through practical visualization.

I learned how DNS, HTTP and SMTP are involved in different application activities.

I also learned how Flask can provide a backend for a web application and how HTML, CSS and JavaScript can be combined to create an interactive networking dashboard.

## 6. Conclusion

The completed Application Layer Protocol Visualizer provides an interactive demonstration of Browsing, Mail and Streaming.

It connects user activities with their underlying Application Layer protocol communication and presents the messages step by step.

The project also demonstrated how AI assistance can be combined with manual development, testing and verification.
